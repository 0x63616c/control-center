# T-59 Panel maintenance Settings evidence

`panel-maintenance-settings.png` was captured from the Time Settings Storybook
story with the in-app browser at the Panel's fixed `1366x1024` viewport. It
demonstrates the enabled nightly refresh, shared hour/minute wheel pickers,
computed next run, and manual **Run now** action.

The Storybook interaction test also changes the maintenance time to `04:30`
and invokes **Run now**, which is why those values appear in the screenshot.
